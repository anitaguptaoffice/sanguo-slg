# 玩法规则（spec/rules）

本目录是 **战斗（military）** 与 **内政（domestic）** 的可执行规格：实现方（如 MIL-001、DOM-001）应以此为准，不得自行臆造公式。

## 文档索引

| 文件 | 内容 |
|---|---|
| [combat.md](./combat.md) | 兵种克制、伤害、回合流程、胜负 |
| [domestic.md](./domestic.md) | 资源产出、建造耗时与消耗、队列 |
| [params.yml](./params.yml) | **唯一数值真源**（初版可玩默认数） |
| [social.md](./social.md) | 选服、军团、聊天、排行快照与分服写边界（M3） |
| [content.md](./content.md) | 任务链、商城、邮件与发奖队列（M4） |

## 标注约定

每条含数值的规则在正文中使用统一脚注块：

```text
【数值】来源：params.yml → <YAML 点路径>
【调参】改 params.yml 对应键；SPEC-004 管线将其导入静态配置（实现侧只读配置，不写死常量）
```

- **来源**：该数字在仓库中的定义位置。
- **调参**：策划/平衡调数值时只改 `params.yml`（或未来由管线生成的等价表），代码通过配置键读取。

## 与架构的对应

| 规则域 | 消费方 | 计算形态 |
|---|---|---|
| 战斗 | `internal/military` 战斗服 | 纯函数：输入双方部队快照 → 输出战报与伤亡 |
| 内政 | `internal/domestic` 游戏服 | 定时器驱动产出；队列到期事件由调度服投递 |
