# Prepared StartMarch creation

The private entry rechecks current ownership, coordinates, evidence and
ready stock before settlement or the separate HERO claim. The write pass
revalidates both under the same transaction locks, debits ready stock and
creates the order, army and field troops before confirming commit. The
owner index and Hub publish the already committed identity.

A definite create failure rolls back the troop debit and releases any
orphan claim. HERO's already committed force cost is retained. An
unconfirmed commit retires admission and retains the hero for recovery.
After confirmed commit, publication failure also requires recovery
without a replacement order or debit. The entry stays private until the
prepared runtime has its matched arrival and return workers.

After the generation closes, the route returns unavailable before any actor or
city reads. The exact-handler PostgreSQL tests intercept the create COMMIT
acknowledgement and separately isolate a bounded rollback panic in a subprocess.
