# Prepared march gateway assembly

The isolated runtime owner holds exclusive writer access, stages
`RestorePreparedMarches` and calls `WirePreparedMarch` before publishing its
gateway or workers. Recruit and Return share admission over the reviewed
source. The assembly installs both durable Hub callbacks and the terminal
HERO release before activating restore. Startup failure requires a fresh
Server and Hub.

Arrival and return use bounded calls to PostgreSQL. An unresolved outcome
closes shared admission and stops the prepared worker. A confirmed terminal
transition releases only the associated heroes. Release failures remain
visible in logs and retain the claim for startup reconciliation.
