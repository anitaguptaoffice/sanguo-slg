# Prepared Recruit runtime

The owned local composition can wire Recruit V2 before serving. The source
must share the prepared first-city binding and exact reviewed MIL projection.
The gateway authenticates Recruit V2 and omits its legacy city, recruit and
march writers while bound. Retirement continues to reject legacy writers.

The prepared worker starts with a database-clock pass and processes a bounded
batch each second. Failure or shutdown stops admission and attempts a bounded
drain. An unproven ending is never declared drained. The legacy military
scheduler is disabled for the prepared source. Outside writers remain the
runtime's responsibility. This composition does not publish stock to the UI.
