# 路线图

## M0 规格（2–3 周）

- [ ] SPEC-001 领域模型与 DDL
- [ ] SPEC-002 通信协议
- [ ] SPEC-003 核心规则文档
- [ ] SPEC-004 数值数据管线

出口：契约冻结，后续实现不再改接口。

## M1 骨架（3–4 周）

- [ ] PLAT-001 仓库骨架与构建
- [ ] PLAT-002 网关与连接管理
- [ ] PLAT-003 可观测性
- [ ] ACC-001 账号与登录
- [ ] WORLD-001 地图与城池
- [ ] DOM-001 建筑与资源
- [ ] CLIENT-001 客户端骨架

出口：单人可登录、建城、造建筑、资源增长。

## M2 战斗（3–4 周）

- [ ] MIL-001 战斗引擎
- [ ] MIL-002 募兵与行军
- [ ] 战报与复盘
- [ ] 客户端战斗表现

出口：完整战斗闭环，战斗服独立部署。

## M3 多人（4–6 周）

- [ ] 分服与开服流程
- [ ] 军团、聊天
- [ ] 排行与榜单
- [ ] 3000 并发压测

出口：可小范围对外开放。

## M4 内容（持续）

- [ ] 任务系统
- [ ] 道具与商城
- [ ] 活动与运营后台
- [ ] 数据埋点

## 不做

跨服战、赛季、实时 PvP、移动原生、多语言——v1.0 范围外。

## 风险

| 风险 | 影响 | 对策 |
|---|---|---|
| 战斗规则复杂度被低估 | 工期翻倍 | MIL-001 先做原型，用对拍验证 |
| 客户端工作量占比高 | 阻塞上线 | 与 M0 并行启动，占位美术先跑通 |
| 契约频繁变更 | 并行失效 | 每周冻结评审 |
