## Slice `R1-S1`：原版 8 地形世界生成、州郡分区与野地/黄巾守军配置管线

- **参照真源**：`WorldFunc.php`（`getBlockData`、`getWorldCityInfo`）、`mem_world`、`cfg_world_type`（`0..7`）。
- **Schema 与静态配置（`spec/db` + `spec/data`）**：
  1. 升级世界格点表 `world_tile`（或扩展 chunk 存储 + 活跃格点表）：支持 `terrain_type`（`0=城池, 1=平地, 2=荒漠, 3=森林, 4=草原, 5=山地, 6=湖泊, 7=沼泽`）、`level (1..10)`、`max_level (1..10)`、`province_id (1..14)`、`owner_city_id`、`npc_kind (0=普通野地, 1=黄巾军营/城寨)`、`garrison_json`（当前守军残余兵力与守将摘要）、`recover_at`（守军恢复时间）。
  2. 新增 `spec/data/source/world_wild.yml`：定义 `Lv1–Lv10` 各类型野地与黄巾营寨的标准守军编制（随等级从义兵/民夫递进到长枪/刀盾/弓箭/轻铁骑混编）、守将等级/三维区间、资源储量与掉落池权重（宝珠/琥珀/翡翠/加速文书等，文案全新编写）。
- **Protobuf 契约（`spec/proto/sanguo/world/v1/world.proto`）**：
  - `GetWorldViewportRequest { int32 center_x = 1; int32 center_y = 2; int32 radius_x = 3; int32 radius_y = 4; }`
  - `GetWorldViewportResponse { repeated WorldTileSummary tiles = 1; repeated WorldMarchLine marches = 2; }`（含地形、等级、州名、归属玩家/城池/联盟旗号、黄巾标识、交战态，以及视口内可见行军线段）。
  - `GetWorldTileDetailRequest { int32 x = 1; int32 y = 2; }` → 返回格点详情（地形加成百分比、归属信息、公开守军规模档位、可执行动作集合）。
- **后端清理**：彻底删除 `internal/military/combat/garrison.go` 中的 `M2FixtureGarrisons()` `(5,5)` 假数据，守军统一从 `world` 持久化状态与 `world_wild.yml` 配置读取与写回。
- **验收标准**：单测与 PG 集成测试覆盖地图确定性生成、8 地形占比、平地唯一建城约束、视口查询 `< 30ms` 及野地守军定时刷新恢复。

## Slice `R1-S2`：全屏等距世界大地图场景（`WorldMapScene`）与格点交互浮层

- **目标**：把世界地图从“右上角只读小方块 + 表单输坐标”升级为真正的 SLG 全屏可交互场景。
- **客户端实现（`client/src/scenes/WorldMapScene.ts` + `SceneManager`）**：
  1. **场景切换**：顶栏/底栏提供清晰的「世界 / 主城」一键切换（保留状态不重连 WS），从主城切入世界默认居中当前主城坐标。
  2. **视口渲染与交互**：
     - 全屏 Canvas 2D 等距（或斜视角网格）渲染 8 类地形底图、格点等级徽章（`Lv1–Lv10`）、玩家城池（区分己方/盟友/中立/敌对旗帜色）、黄巾营寨标识、己方附属野地旗帜；
     - 实时绘制出发地→目的地动态行军虚线、部队行进方向图标与剩余倒计时；
     - 支持鼠标拖拽平移（带视口分块节流拉取 `GetWorldViewport`）、滚轮缩放（2 档）、输入 `(X, Y)` + 州郡快速跳转、「回到主城坐标」复位按钮。
  3. **格点点击交互菜单**：
     - 点击任意格点高亮选中框并拉取 `GetWorldTileDetail`，在格点旁弹出操作浮层：
       - 未占领野地：`查看详情`、`占领`、`掠夺`、`侦察（R4 解锁前置灰提示）`；
       - 黄巾营寨：`查看详情`、`讨伐掠夺`；
       - 己方附属野地：`查看详情`、`派遣驻军`、`采集寻宝`、`放弃野地`；
       - 己方主城：`进入主城`。
- **验收标准**：1280×720 与 1600×900 分辨率下拖拽达到 60fps；占位纹理与正式瓦片（`R1-S6`）通过 `AssetLoader` manifest 无缝兼容；点击野地可直接唤起预填好目标格信息的出征面板。

## Slice `R1-S3`：将领统兵出征、行军召回（`RecallMarch`）与行军加速

- **参照真源**：`GroundFunc.php`（`StartTroop`）、`TroopFunc.php`（`callBackTroop`、`speedTroop`）。
- **契约与规则（`military.v1`）**：
  1. **将领强制统兵与带兵上限**：
     - 掠夺（`purpose=3`）与占领（`purpose=4`）必须指定本城 `status=Idle` 的将领（`hero_id > 0`），出征原子扣减将领体力（`march_force`）并将将领置为出征态；
     - 校验带兵总数 `Σ troops.count <= HeroCommandCap(hero, ground_level, technic_command_level)`（基础值：`校场等级基数 + 将领统率 × 100`，为 R2 统帅科技预留乘区）；
     - 校验同时在外行军/驻军支数 `<= 校场等级`（R1 主城未细分校场前按官府等级保底，R2 无缝切校场 `bid=8`）。
  2. **行军耗时与耗粮**：
     - 采用欧氏距离公式：`ceil(sqrt(dx² + dy²) × 6000 / min_unit_speed)`（设最小保底秒数防零秒瞬移），出征扣减单程行军口粮。
  3. **行军召回与加速新 RPC（正式解禁）**：
     - `military.v1.RecallMarch`：对处于 `MARCH_PHASE_MARCHING`（去程未到达）或驻守态（`STATIONED`）的己方部队发起召回；去程半途召回按**已走耗时等距折返**（`return_finish_at = now + (now - depart_at)`），立即转为 `MARCH_PHASE_RETURNING`。
     - `military.v1.SpeedupMarch`：消耗行军加速道具（如急行军令）按比例或固定时长缩短当前去程/返程剩余时间。
- **客户端体验**：出征弹窗展示可选闲置将领下拉列表（显示等级、统率带兵上限、勇武、智谋、当前体力）、各兵种滑块/快捷最大配兵、实时预计单程时间与耗粮；军情列表与大地图行军浮层提供「召回」与「加速」按钮。
- **验收标准**：无将或超统率出征明确拦截；去程第 10 秒点召回，准确在 10 秒后回城退兵并释放将领为空闲态；服务器重启不丢在途与折返状态。

## Slice `R1-S4`：真实野地/黄巾战斗结算、将领三维加成与完整战报

- **参照真源**：`HeroFunc.php`、`ReportFunc.php`、`internal/military/battle`。
- **战斗与结算规则**：
  1. **将领三维入战**：
     - 攻方将领与野地/黄巾守将均参与属性折算：`有效攻击倍率 = 1 + bravery(force) / 200`，`有效防御倍率 = 1 + wisdom(intel) / 200`，叠加兵种克制与等级修正后进入战斗模拟。
  2. **真实守军扣减与战后掉落/经验**：
     - 攻打野地/黄巾读取格点当前真实守军；战败或平局时更新格点残余守军（允许玩家派第二波部队补刀，直至 `recover_at` 刷新）；
     - 攻方无论胜负按消灭敌军总人口/经验值结算主将战斗经验（达标自动升级并增加潜能点）；
     - 击败黄巾营寨或掠夺野地：按存活部队剩余总 `carry` 结算粮/木/石/铁/黄金战利品，并按 `world_wild.yml` 概率抽取掉落道具，返程到家时与存活士兵一并原子入账（`player_wallet` + `player_bag`）。
  3. **战报协议扩量（`military.proto`）**：
     - `BattleReportSummary` 与 `BattleReportDetail` 新增：`target_name`（如 `森林 Lv4`、`黄巾前哨 Lv3`）、`purpose`（掠夺/占领）、`attacker_hero` / `defender_hero`（姓名、等级、三维摘要）、`loot_resources`（五资源明细）、`loot_items`（道具 ID 与数量）、`hero_exp_gained`。
- **客户端战报面板**：移除“对手信息未记录”占位文案，完整展示攻守双方主将名片、逐兵种参战/阵亡/存活对比表、每回合伤害摘要、掠夺资源与战利品图标列表，支持点击坐标一键切回 `WorldMapScene` 定位该格点。
- **验收标准**：高武力主将对比低武力主将同兵力战损显著降低（单测固定随机种子对拍）；打赢黄巾返程后钱包、背包道具、将领经验与战报记录四账完全一致。

## Slice `R1-S5`：附属野地占领、主城产量加成与派遣采集寻宝闭环

- **参照真源**：`CityFunc.php`（`getCityField`、`updateFieldResourceAdd`、`gatherFieldStart`、`gatherFieldEnd`、`discardField`）。
- **核心玩法规则**：
  1. **占领上限与归属切换**：
     - 当行军目的为 `占领 (purpose=4)` 且战斗获胜时，校验出发城池当前已占领野地数 `< 官府等级`：
       - 未达上限：格点 `owner_city_id` 设为出发城池，部队转为驻守该野地（`MARCH_PHASE_STATIONED`），或允许一键调回主城保留野地归属；
       - 已达上限：自动降级为仅击败不占领并在战报中明确提示“官府等级不足，附属野地已满”，部队携战利品返程。
  2. **主城资源小时产量加成**：
     - `domestic` 计算城池资源小时产量时，实时汇总本城全部附属野地加成（如占领 `Lv5 森林` → 木材小时基础产量 `+25%`，`Lv4 湖泊` → 粮食 `+28%`），在主城顶栏资源悬浮提示与内政总览中清晰拆解「建筑基础产 + 野地加成」。
  3. **野地管理与派遣采集（`world.v1` / `domestic.v1`）**：
     - 新增「附属野地」管理视图（列出本城占领的全部野地坐标、地形等级、产量加成、驻军状态）；
     - 支持**放弃野地**（若有己方驻军则自动触发返程，清空 `owner_city_id` 并重排野地守军刷新计时）；
     - 支持对已占领野地发起**采集（`StartFieldGather` / `ClaimFieldGather`）**：派遣空闲将领 + 耗粮持续采集（如 1 小时），到期按野地地形与等级结算基础资源与宝物珠玉（珍珠/珊瑚/琉璃/琥珀/翡翠/玉石/夜明珠，为 R3 名将招降与爵位晋升提前产出核心材料）。
- **验收标准**：真实浏览器 E2E 跑通「Lv2 官府占领第 1、2 块野地主城产量实时上涨 → 尝试占第 3 块提示上限并自动返程 → 采集满期领到对应地形宝物 → 放弃野地后主城产量加成即时回落」。
