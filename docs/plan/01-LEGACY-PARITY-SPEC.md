## 一、世界地图、州郡与野地体系（对标 `WorldFunc.php` / `mem_world`）

### 1. 坐标系与州郡划分
- **原版规模**：`500 × 500` 格（`250,000` 格，`wid` 编码区块），划归 **13 州 + 司隶**（幽、冀、并、青、兖、豫、徐、扬、荆、益、凉、交、司隶等，含开服州开放状态控制）。
- **本仓实现口径**：支持配置化地图边长（开发态可跑 `200×200` 提速初始化，开服配置 `500×500`），格点持久化字段必须包含：`server_id, x, y, terrain_type, level, max_level, province_id, prefecture_id (jun), owner_city_id, tile_state (0=和平, 1=交战), npc_city_id, updated_at`。

### 2. 八大格点类型（对标 `cfg_world_type`）

| `terrain_type` | 地形名称 | 可建城/筑城 | 占领对归属城池的资源产量加成（`Lv1–Lv10`） | 采集特殊产出方向（对标 `cfg_things` / 宝物） |
|---:|---|---|---|---|
| `0` | 城池 | 已被玩家城/黄巾城/历史名城占用 | — | — |
| `1` | 平地 | **唯一可建主城/筑分城地形** | 无产量加成（用于筑城或刷野练将） | 铜钱、古朴木盒、招贤文书残页 |
| `2` | 荒漠 | 否 | 石料小时基础产量 `+5% × level` | 琉璃、玛瑙、琥珀 |
| `3` | 森林 | 否 | 木材小时基础产量 `+5% × level` | 琥珀、翡翠、灵芝 |

### 3. 野地与黄巾驻军刷新规则
- **野地守军**：未占领野地（`owner_city_id = 0`）按 `level (1..10)` 生成对应阶梯兵种与随机等级野地守将（等级越高出现骑兵/弓兵/器械混编）；被击败但未占领或放弃后，按定时调度器恢复守军；午夜维护时未占领野地等级在 `1..max_level` 间循环升降。
- **黄巾城 / NPC 城池**：地图按州郡分布 `Lv1–Lv10` 黄巾营寨/城池（拥有城防、可再生资源池与守军，是玩家日常“刷黄”掠夺粮木石铁黄金与刷将领经验的核心来源）。

## 三、城市人口、民心、税收与资源经济公式（对标 `CityFunc.php`）

这是《热血三国》内政循环的心脏，R2 必须完整替换掉 M1 的静态加法：

1. **民心平衡公式**：
   - `目标民心 = clamp(100 - tax_rate - complaint, 0, 100)`（`tax_rate` 税率 `0..100`，`complaint` 民怨 `0..100`；被攻城掠夺涨民怨，官府“安抚百姓”消耗粮食降民怨提民心）。
   - 当前 `morale` 按固定时间刻度向 `目标民心` 渐近收敛。
2. **人口收敛公式**：
   - `人口上限 (max_population) = Σ 民房各等级基础人口`；
   - `稳定人口 (target_population) = floor(max_population × morale / 100)`；当前 `population` 按周期向 `target_population` 增长或流失。
3. **劳力与资源小时净产量**：
   - `所需劳力 (labor_needed) = Σ(四大资源田各建筑等级所需劳力 × 开工率)`；
   - `劳力效率系数 = min(1.0, population / max(1, labor_needed))`；
   - `单项资源小时毛产 = 基础自然产 + Σ 对应资源田基础产 × 劳力效率系数 × (1 + 对应生产科技加成 + 城守内政属性加成 + Σ 附属野地加成)`；
   - `粮食小时净产 = 粮食小时毛产 - 城内驻军与在外归属部队小时耗粮 (Σ count × food_use × (1 - 补给技巧加成))`（缺粮时触发逃兵/哗变规则）。
4. **空闲人口与募兵**：
   - `空闲人口 = population - 实际占用劳力`；训练士兵必须扣减 `count × people_need` 空闲人口（解散士兵返还部分人口）。
5. **黄金税收**：
   - `黄金小时收入 = floor(population × (tax_rate / 100) × 基础税系数 × (1 + 商贾之利科技加成 + 城守内政加成)) - Σ 在职将领小时俸禄`。

## 六、出征任务与战术战斗模型（对标 `GroundFunc.php` / `TroopFunc.php`）

### 1. 六大行军任务（`march_purpose`）
1. **运输（`0`）**：己方分城或同盟城池间运送黄金/粮/木/石/铁，校验部队总 `carry >= 携带资源总量`。
2. **派遣（`1`）**：调兵/调将驻防己方分城、附属野地或开启鸿胪寺接纳的盟友城池。
3. **侦察（`2`）**：必须包含 `斥候 (sid=3)`，不带主将亦可出发；按斥候数与 `侦察技巧` vs 目标 `烽火台` 产出情报战报（发生反侦察时斥候交战损耗）。
4. **掠夺（`3`）**：必须指定空闲主将（`hero_id > 0`）并扣减体力；击败野地/黄巾/玩家城池后按剩余部队 `carry` 掠夺非仓库保护资源与掉落并立即返程。
5. **占领（`4`）**：必须指定空闲主将；对野地战胜且附属野地未满官府上限时直接占为附属野地并驻军；对玩家分城/历史名城战胜时扣减目标城池民心/统治度，归零时夺取城池控制权（玩家唯一主城不可被夺走，仅可被掠夺破墙）。
6. **筑城（`5`）**：爵位允许拥有额外城池时，派遣民夫 + 五种基础资源赴已占领的 `平地 (terrain=1)` 修筑新分城。

### 2. 行军耗时与射程回合制战斗演进路径
- **行军耗时**：`欧氏距离 sqrt(dx² + dy²) × GRID_DISTANCE(6000) / (部队最慢兵种加成后速度)`，叠加行军/驾驭/车轮科技与驿站/烽火台加成。
- **战斗引擎分两步对齐**：
  - **R1 阶段**：在现有回合框架上立即补齐**主将三维加成**（统率有效带兵比、勇武加攻击、智谋加防御、军师智力加成）与真实守军/战利品结算，快速打通大地图 PvE。
  - **R3 阶段**：完整升级为**原版一维战场距离推进引擎**（战场初始总长 = 参战双方最大射程兵种/城墙箭塔射程 + 缓冲距；每回合按速度由快到慢行动，射程内有目标则按玩家预设 `cfg_troop_tactics` 优先目标攻击，射程外则向前推进移动，最多 40 回合判定胜负与破墙）。

## 七、将领、历史名将、装备与终局国战（R3–R5 索引）
