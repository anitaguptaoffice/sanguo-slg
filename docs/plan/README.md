# `sanguo-slg` 1:1 深度复刻重规划总览（2026-11-18）

本目录是 `sanguo-slg` 面向后续执行 Agent 与多 Agent 协调器（Herdr）的**唯一权威规划与施工蓝图**。

---

## 一、为什么要推倒旧节奏重规划？（前车之鉴）

截至 `main` @ `52faf12`（累计 3,149 个历史 Issue/PR），项目在账号、基础主城 7 槽、客栈招将、基础商城/邮件/聊天/排行及首批原创立绘/道具图标上已有可用底座，但**核心 SLG 可玩性严重停滞**。后续任何 Agent 严禁重蹈以下四个覆辙：

1. **前端波次空转堆叠**：历史 `wave:20–59` 在 `client/src` 制造了 `516` 个 `*Residual*` / `*Deep*` / `*Sweep*` / `*NarrowManifest*` 垃圾文件（`46,074` 行，占前端近 59%），不断叠加无意义的只读状态行，却未实现全屏世界大地图与内外城正式界面。
2. **后端过度形式化与双轨分裂**：历史 PR [#1900](https://github.com/anitaguptaoffice/sanguo-slg/pull/1900)–[#3149](https://github.com/anitaguptaoffice/sanguo-slg/pull/3149) 投入在 PG OID 钉死、`COMMIT` 断连穷举与浏览器外部 Python 恢复守卫上，造出一套仅允许 `loopback` 本机运行、禁用 GM HTTP、强绑本地 profile 文件的 `Prepared*` 分叉模式，与默认 `make dev` 分裂且无法正常开服部署。
3. **世界与战斗停留在玩具假桩**：全服仅 `internal/military/combat/garrison.go` 中 `(5,5)` 一个内存假驻军点（打完即消失），无野地占领/采集、无黄巾/名城、无 PvP 攻掠，且将领属性未接入战斗结算（传 `heroLevel=0`）。
4. **旧交接禁令自我锁死**：旧文档禁止 `CancelMarch`、禁止加速、禁止扩充建筑/科技 RPC、锁死 `DATA-002` 行数上限，把《热血三国》最核心的策略循环挡在了门外。

## 二、重规划核心决策（已由项目负责人拍板冻结）

| 决策维度 | 冻结结论 |
|---|---|
| **终极产品目标** | **《热血三国》原版全量系统 1:1 深度复刻**（规则、公式、建筑/科技/兵种/名将/装备/国战体系对齐 `origin/reference/legacy-source`；代码、DDL、文案、美术 100% 原创重制） |
| **存量代码处置** | **外科手术式清理 + 后端单轨合一**：铲除前端 4.6 万行 `Residual/Deep*` 废代码，将后端 `Prepared*` 收敛回单一可远程部署的常规 PG 服务，复用已有协议底座、PG 表与原创美术资产 |
| **研发治理模式** | **垂直功能切片（Vertical Slice）交付**：废除旧玩法禁令、400 行切卡与极端故障注入仪式；按玩家可感知端到端功能切片交付，采用标准 PG ACID 事务 + 真实浏览器可玩门禁 |
| **首战突破口（M-Next）** | **Phase R1：全屏世界大地图交互 + 真实野地/黄巾驻军战斗 + 将领统兵入战 + 占领/采集产出闭环** |
