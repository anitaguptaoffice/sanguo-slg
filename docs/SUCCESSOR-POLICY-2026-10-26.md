# 接手阶段工作约定（2026-10-26）

本文件说明接手阶段的工程与美术工作边界。旧波次、样件合同和 QA 记录保留其历史语境；其中关于旧编排者停工、旧卡仅美术或旧样件不改服务端的限制，不扩展为接手阶段的全项目禁令。

## 1. 可自主推进的工作

- 接手编排者可围绕本项目可玩性目标，自行决定工程修复与原创美术的优先级，开发、修改并发布新分支 / PR；新修复通过审阅、适用测试和 CI 后可自主合并。
- [停工交接](./HANDOVER-2026-10-26.md) §1 / §8 的 wave:59 停工对象是**旧编排 bot**，不是接手团队。无需恢复旧 bot 或复用旧 wave，才能继续修复客户端、服务端及其集成。
- 可自行建立独立、有明确 scope / 依赖 / 验收条件的任务卡和 contract PR；由编排者维护任务清单及对应 issue，不必因旧卡没有覆盖新缺口而重复等待开卡许可。starterbook、服务端权威新手引导等缺口也须按此拆卡，不能塞入既有美术卡。
- 「仅美术」「不改服务器 / RPC」「不新增工程」若来自旧美术任务、样件或旧编排阶段，只约束其原任务。新工程卡仍须限定域和文件范围；需要另一域配合时另开卡协调，不在一个实现 PR 中越界。

## 2. 仍须满足的交付门槛

- 继续遵守 [AGENTS.md](../AGENTS.md)：一卡一 PR、改动 ≤400 行、域所有权与 scope、审阅、相关单测 / 集成测试、文档和 CI；未验证事项必须明示，不能以授权替代验收。
- `spec/proto/`、`spec/db/` 变更仍走**独立 contract PR**，列出受影响域和任务，评审合并后再推进依赖实现。可创建和评审新契约，不等于可以在实现卡里修改冻结契约。
- 当前适用的契约冻结及依赖门槛仍须满足；将冻结作为阻断条件时，须指出可核验的当前有效日期 / 时窗、适用范围和解除条件，不能因缺少日期把每周冻结解释为永久禁令。历史里程碑的「冻结」或某批样件的 DRAFT 状态，不自动冻结接手阶段独立评审的新契约，也不代表旧契约已获通过；有效的具体冻结不得绕过。
- 原创资源的新绘、修复、工程接入分别在明确的美术 / 接入卡验收。工程实现卡不夹带 art PNG；修改 schema 仍由对应工程合同承担。布局、倍率、透明边、运行时挂载与视觉验收要求不因本文件免除。

## 3. 明确保留的限制

- **历史参考、art hold 与 VERIFY hold PR 继续不合并**，包括 #77 / #82 / #108、[交接 §4](./HANDOVER-2026-10-26.md#4-永不合并art-hold--verify-draft) 所列及各样件记录中的 hold。交接中的「接手方自行决定 hold」不是当前放行依据。不得通过改名、换分支或新 PR 整体搬入被 hold 的内容来规避限制。
- 新修复 PR 的可合并权限不适用于上述历史 hold；任何合规的原创资源接入仍须独立范围、来源核验与验收，不能沿用旧 PASS 宣称新版本已验收。
- [原版资料](./reference.md) 只读，不复制原版代码、文案、美术到主树，不打包参考资料；既有 QA 的 SHA、PASS / BLOCKED / 未测试结论不得追改为新版本证据。
- 数据基线仍为 **DATA-002**；**不做 DATA-003 / `cfg_act*` / 不可逆消费扩量 / 花钱类 / IAP / 新商城 SKU 扩量**。
- `CancelMarch`、募兵加速、主城建造 / 募兵新 RPC、战报 proto 扩量等历史范围外功能，不因解除仅美术限制而自动纳入修复卡。需要新范围时先单列契约与验收；世界瓦片 / 图集大规模接入仍按独立美术合同推进。
- 本约定不修改仓库保护、外部权限、工具安全限制、凭据或生产部署审批；遇到真实拒绝或未决权限，不通过修改规则绕过。

## 4. 使用旧文档与任务工具

- [ROADMAP](./ROADMAP.md)、[任务波次记录](../tasks/README.md) 和 `docs/art/samples/` 是历史进度与验收证据，不能把「本波范围外」理解为永久禁止独立新卡，也不能把历史完成记录当成当前版本的验证。
- [美术管线](./art/README.md) 的 #100 开工顺序、DRAFT 状态及 [武将批次文档](./art/hero-avatar-bust-batch.md) 的早期交付状态均有批次语境。新工作应核对当前 main、对应合同及样件证据，不必合并历史 hold 才能开始。
- 不把 `.github/workflows/tasks-sync.yml` 的手动 `workflow_dispatch` 当作接手阶段默认入口：当前该入口固定同步 wave:19，还会尝试关闭 #306–325。应先核对目标卡和同步范围，不能为了开新卡重放旧批次流程。
- `tools/tasks_sync.py` 的现有 issue 查询上限为 500，广泛重放可能漏认旧卡并重复创建；`--dry-run` 不读取现有 issue，不能证明没有重复。只对核对过的目标范围同步，不自动重写 backlog、重开历史卡或改定时任务。

本文件只澄清接手阶段的工作权限与既有门槛，不重写历史成果，也不授予范围外行为的一揽子许可。
