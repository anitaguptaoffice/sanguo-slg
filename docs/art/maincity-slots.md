# 主城槽位显示约定（DRAFT）

## 协议与键名（不可变）

- 升级/建造：`slot_key`（`hall`, `farm`, `lumber`, `quarry`, `iron`, `barracks`, `wall`）。
- **禁止**改升级协议或重命名 `slot_key`。

## 坐标系（必读）

| 规则 | 说明 |
|---|---|
| **坐标系名称** | **全布局坐标（layout frame）**，外框 1600×900。 |
| **舞台范围** | x∈[0,1600)，y∈**[56, 844)**，高 788。 |
| **表中 x、y** | 均为全布局坐标；**已包含顶部 HUD 56px**，实现时 **禁止对 y 再加 56**。 |
| **舞台局部换算** | 仅文档换算：`stageY = layoutY − 56`（例如官府 layoutY=120 → stageY=64）。 |
| **背景** | `mc.bg.plateau.v1` 逻辑 1600×788，左上角对齐 **(0, 56)**，与舞台同域。 |

`display` / `hit` 单位：逻辑 px（1600×900 外框）。`ground_anchor` 相对 **display 矩形左上角**。

## 占位尺寸声明

`MainCityScene` 的 **100×72** 色块 **不是**美术目标尺寸。
