# 军情按 ID 深链可见性

任务 CLIENT-MARCH-ID-VISIBLE-001 / #2058，基线 33cb8af。

## 玩家路径

MainCityScene 的军事汇总（1608）、队列横幅（1648）、小地图点击（2172）和 HUD 待办（2922）调用 `selectMarchById(id, { openPanel: true })`。旧实现只改 selectedMarchId，旧目的格点/阶段仍可隐藏该行。此问题无需请求乱序，已加载两条行军后就能同步复现。

显式打开型深链现在只解除排除目标的不兼容筛选，保留兼容目的地、阶段和 ETA 排序。普通 `selectMarchById(id)` 保持原来的选择行为。按目的地入口复用同一筛选调整逻辑。

## 延迟目标与意图归属

目标未出现在已加载快照时，发起一次既有只读列表刷新；后续成功列表刷新或小地图权威快照可满足该一次性意图。缺失时不虚构行，也不增加无限重试/新的轮询策略。网络失败后允许原有刷新重试。

待定位意图受 actor/session generation、城市、挂载代际、中心面板前台意图保护。用户改目的地、阶段、排序、输入手动坐标、选其他行、另一个深链、出征交接、关闭或换面板后，旧意图不再调整筛选。目标首次显示即消费意图，之后用户筛选和行军阶段变化按原规则生效。

## 验证及边界

- 修改前挂载 DOM 测试：5 失败 / 12 对照通过，证实已加载目标与延迟快照目标仍被隐藏。
- 覆盖兼容过滤、排序保留、只读失败重试、目标消失、延迟出现、手动输入/选择、关闭重开/其他面板、换会话/城市、detach。
- 无服务端、协议、mutation、权限或部署改动。不改任何 held draft；当前 held PR 无同文件交集。
- mounted DOM/controller 测试不是原生浏览器或真实服务器端到端验收；本卡为既有只读数据的非视觉选择修复，不宣称完整游戏验收。
