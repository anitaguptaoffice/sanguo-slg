# 普通任务列表选择

CLIENT-QUEST-ROW-SELECTION-001 / #2062。基线 d575a1d。

普通任务面板承载新手链100，日常面板只覆盖400/401。以前这里仅显示纯文字列表，操作只能手写任务ID，默认1001；点击1002文字再领奖仍然提交1001。本卡为新增可玩性交互，不把旧列表声称为已有点击契约。

每条合法任务行增加原生「选择」按钮。按钮只同步既有ID控件和内部选择，不自动接取/领奖；「已选」文字和 aria-pressed 同步，点击不会重建按钮或丢失焦点；异步刷新若重建列表，只恢复原本聚焦且仍存在的任务按钮，不从其他控件/隐藏面板抢焦点。之后显式接取/领奖沿用原有处理，包括奖励资产对账。手动输入仍可使用未出现在列表的ID，刷新不偷偷改变它；缺失行不显示虚假选中态。

服务端 GetQuestChainStatus 对未来未接取节点也可能返回 AVAILABLE，前置任务/等级仍可能阻止接取。因此这里不使用状态枚举替代服务端规则，不自动启用流程或推断可接取。
