# 英雄到背包异步导航归属

CLIENT-HERO-BAG-NAVIGATION-001 / #2060；基线 6698a9f。

两个英雄详情入口（前往背包、相关道具）先读取 ListPlayerBag，成功后经 MainCityScene 回调打开真实 ContentPanels 背包。旧实现没有校验读取期间的导航变化，还会把相关道具的返回英雄取自响应时的可变选中值。

## 真实顺序与修复

复现无需服务端乱序：点击英雄 A 的背包入口，尚未收到包列表就改开商城或选择 B。按 FIFO 完成 bag→shop 或 bag→detail(B)，旧 bag 回调仍会打开背包并覆盖新界面。关闭、返回列表和关闭重开同样可达。

每次入口现在捕获独立链接/导航代际、原始英雄、actor/session 与中心面板意图。新选择、同英雄重选、A→B→A、Back、转到招募区、关闭/重开、其他面板、重连/换账号/城市、卸载后重挂均压制旧导航与反馈。两个入口共用链接代际，多次点击以最新请求为准，不重发请求。

数据更新与导航分离：加点成功或 receipt 驱动的只读详情重对账不取消用户之后点击的背包入口；选择/重新选择/返回列表才使它过期。

正常成功仍定位同一道具并返回发起英雄；当前相关道具读取失败时仍使用已捕获的会话背包。取消后的失败不能借 fallback 重新打开背包。仅取消客户端导航，不改变服务端请求。
