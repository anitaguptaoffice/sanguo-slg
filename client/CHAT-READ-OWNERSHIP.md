# CLIENT-CHAT-READ-OWNERSHIP-001

聊天读取按账户、挂载及当前频道/私聊对象/军团隔离；相同活动目标复用请求，切换目标发起独立读取。频道或私聊输入变化即清理旧消息及未读标记，私聊目标完成编辑（change）后读取新对象。旧成功、错误及收尾不覆盖当前列表、未读快照或刷新状态，频道往返也不复用过期请求。

保留发送草稿安全及发送触发读取的目的地保护。无协议/后端/军团/排行变更，不发送或重发任何用户消息。测试 `SocialPanels.chatRead.test.ts` 覆盖乱序、失败、目标切换、去重、未入军团、重挂/重登录、未读隔离；既有发送和社交测试必须回归。DOM 测试不是浏览器视觉验收，未运行实际浏览器。
