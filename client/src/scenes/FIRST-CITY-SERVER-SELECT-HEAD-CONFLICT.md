# ServerSelect HEAD_CONFLICT intake display

CLIENT-FIRST-CITY-HEAD-CONFLICT-001 ([#2704](https://github.com/anitaguptaoffice/sanguo-slg/issues/2704)) stacks on #2702.

Loopback ServerSelect V2 first-city panel shows **read-only** rows for retained `headConflict` observations from
Submit/Continue: the requested command id and the observation's **actual** durable head (command name/coordinates or EMPTY).
Canonical winner, losing-proposal and same-ID local-draft lines remain separate. Stale-actor, unavailable and incomplete
evidence withhold the display. No automatic Continue/Submit, no main-city navigation, no playable-first-city claims.
