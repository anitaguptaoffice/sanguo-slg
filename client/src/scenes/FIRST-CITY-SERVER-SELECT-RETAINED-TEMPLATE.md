# ServerSelect retained template ref read-only display

CLIENT-FIRST-CITY-RETAINED-TEMPLATE-001 stacks on #2734.

Loopback ServerSelect V2 first-city panel shows **read-only** server-retained `TemplateRef` from the durable `head` command
record ([FIRST-CITY-WIRE.md](../../../spec/proto/FIRST-CITY-WIRE.md) §4). This is not caller intent, proposal summary,
PENDING intake text, or terminal receipt fields. Authorized scope, outcomes, and stale-actor isolation stay separate.
No automatic Submit/Continue or main-city entry.
