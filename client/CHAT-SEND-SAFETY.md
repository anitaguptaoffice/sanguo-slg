# CLIENT-CHAT-SEND-SAFETY-001

聊天发送期间禁用重复提交，发送成功只清理未被改写的已发送草稿；输入编辑、频道/私聊目标切换和新挂载的草稿不被旧回包删除。失败保留输入，用户可以主动重试，不自动重发。已经发出的服务器消息不撤销。

发送及其主动发起的聊天回读使用账户与面板所有权检查，旧 finally 不解除新发送锁。一般聊天列表的并发频道切换治理另卡处理，不能把本卡视为全部社交请求的生命周期保证。

验证：`SocialPanels.chatSend.test.ts` 覆盖防重、草稿编辑后改回、成功/失败、目标切换、同玩家重新登录、卸载重挂及发送触发回读。既有社交回归、完整客户端测试与 build 另行运行；没有布局/素材变化，DOM 测试不等于真实浏览器视觉验收。
